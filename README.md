# Project Hierarchy Hub

create a hierarchy structure for project by creating feature of creating WBS within project, Activity withing WBS and Milestone within Activity. All project, wbs, activity and milestones to have relevant fields. Dates in wbs, activity and milestone should roleup to upper hierarchy level
